# Bansal Long COVID Baseline Data

Baseline Olink proteomics data from the Bansal & Olechnowicz Long COVID
study. Contains 182 protein measurements and clinical variables for 57
subjects.

## Usage

``` r
bansal_baseline57
```

## Format

A data.table with approximately 10,000 rows and 24 columns, including
clinical variables and NPX values.

## Source

Bansal A, Olechnowicz SWZ, et al. (2026). Divergent inflammatory and
neurology-related protein levels in long COVID following primary and
breakthrough SARS-CoV-2 infections. Communications Medicine.
[doi:10.1038/s43856-026-01541-6](https://doi.org/10.1038/s43856-026-01541-6)
