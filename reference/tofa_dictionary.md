# TOFA Data Dictionary

Variable descriptions for the TOFA Down Syndrome Olink dataset.

## Usage

``` r
tofa_dictionary
```

## Format

A data.table with 15 rows and 3 columns:

- variable:

  Variable name

- description:

  Human-readable description

- type:

  Data type

## Source

Rachubinski AL, et al. (2024). JAK inhibition decreases the autoimmune
burden in Down syndrome. eLife.
[doi:10.7554/elife.99323](https://doi.org/10.7554/elife.99323)
