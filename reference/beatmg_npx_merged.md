# BeatMG NPX Merged with Demographics

BeatMG NPX data left-joined with demographic annotations by SubjectID,
carrying clinical context onto every NPX row.

## Usage

``` r
beatmg_npx_merged
```

## Format

A data.frame with approximately 112,000 rows and 60 columns. Combines
columns from beatmg_npx and beatmg_demo.

## Source

BeatMG study (ClinicalTrials.gov NCT02110706). Nowak RJ, et al. (2022).
Phase 2 Trial of Rituximab in Acetylcholine Receptor Antibody-Positive
Generalized Myasthenia Gravis: The BeatMG Study. Neurology.
[doi:10.1212/WNL.0000000000013121](https://doi.org/10.1212/WNL.0000000000013121)
