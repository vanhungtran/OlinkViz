# Bansal Long COVID Univariate Results

Univariate (Wilcoxon) test results comparing protein expression between
groups for 182 proteins from the Bansal Long COVID study.

## Usage

``` r
bansal_univariate
```

## Format

A data.table with 182 rows and 14 columns of per-protein statistical
test results.

## Source

Bansal A, Olechnowicz SWZ, et al. (2026). Divergent inflammatory and
neurology-related protein levels in long COVID following primary and
breakthrough SARS-CoV-2 infections. Communications Medicine.
[doi:10.1038/s43856-026-01541-6](https://doi.org/10.1038/s43856-026-01541-6)
